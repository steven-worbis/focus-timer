# Focus Timer

A minimal Pomodoro-style focus timer built with plain HTML, CSS, and JavaScript — no dependencies, no build step.

## Features

- Focus, short break, and long break modes
- Circular progress ring
- Session tracking with streak counter
- Adjustable durations via settings panel
- Dark mode support
- Browser notifications

## Usage

Open `index.html` in any browser. No installation required.

## Settings

| Setting | Default |
|---|---|
| Focus duration | 25 min |
| Short break | 5 min |
| Long break | 15 min |
| Sessions until long break | 4 |
